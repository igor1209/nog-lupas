# NOG Lupas

Estrutura do site:

- `index.html` e `404.html`: entradas do GitHub Pages, mantidas na raiz.
- `css/`: estilos gerais (`estilos.css`), aparência (`aparencia.css`), conta e sacola (`conta-sacola.css`) e página 404 (`erro.css`).
- `js/`: catálogo (`catalogo.js`), interface (`interface.js`), conta e sacola (`conta-sacola.js`).
- `assets/`: imagens, logotipo e recursos.

Abra `index.html` através de um servidor local ou do GitHub Pages.
